# 📒 Contact Book

## 📌 Description

This is a beginner-friendly Python Contact Book project. It allows users to add, search, display, and delete contacts through a menu-driven interface. The project was built to practice Python fundamentals such as functions, dictionaries, loops, conditional statements, and user input.

---

## ✨ Features

- ➕ Add a new contact
- 🔍 Search a contact by name
- 📋 Display all saved contacts
- ❌ Delete a contact
- 🔄 Menu-driven interface
- 🚪 Exit the program

---

## 🛠️ Concepts Used

- Python Functions
- Dictionaries
- While Loop
- If-Else Statements
- User Input (`input()`)
- Dictionary Methods (`items()`)
- Delete Operator (`del`)
- `break` Statement

---

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Run the `contact_book.py` file.
4. Choose an option from the menu.
5. Add, search, display, or delete contacts.
